Overview
Meant to mimic a bank and a set of accounts for customers Ann and Bob. There are two different accounts being checking and saving accounts. Checking is meant to just hold a balance while Saving is meant to accrue interest over time.

Reflection
This project was very daunting at first when I had looked at it especially since, Go is a very odd looking language to me. Although being new to the language being able to use the Go website which has a lot of good notes on how to use the language was very helpful. It also made it a lot easier that I was translating and not writing it from scratch as I had something to work off of instead of being thrown in the deep end. I did realize I gave myself a lot less time than I wanted, I figured it wouldn't be too bad so I started 4 days before. So next time I know to give myself more time.
There were points that I struggled like with the pattern of the functions but once I understood the pattern I feel like I did pretty well once I started doing a bunch of them. It was also super weird since there was no void so just leaving it blank felt really weird. This also feels dumb to say but I also sometimes forgot whether I capitalized something or lowercase while also forgetting some good go naming conventions so that really made it a lot harder for me
